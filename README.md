Task 2 uses the official Superstore dataset (9,994 orders, 2014–2017). Built in Power BI: imported the CSV, added Sales/Profit/Margin measures, and created 6 visuals — a Sales-vs-Profit yearly trend, profit by Category and Sub-Category, a discount-bucket vs profit chart, and Region/State profit comparisons. Conditional formatting flags losses in red, profits in teal. Key story: sales and profit both grew (+51%/+89%), but Furniture — specifically Tables and Bookcases — loses money once discounts exceed 20%, with Texas, Ohio, and Pennsylvania hit hardest. A summary page ties each insight to a recommended action. Exported as PDF.
